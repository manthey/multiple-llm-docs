# Multiple LLM docs

A plugin for Obsidian (https://obsidian.md) that lets you chat with LLMs in plain markdown files.

## Source

This was forked from (https://github.com/shane-lamb/obsidian-llm-docs), with the following major changes:

- Works on mobile
- Can run on a sequence of models
- Supports tools use
- Supports passing more parameters to models
- Improved image processing, link following

My use case is virtually all local (ollama and local tools)
